# Plan: Create ARCHITECTURE.md for React WordPress Theme Template

## Goal
Create a comprehensive `ARCHITECTURE.md` at `themes/react_template/ARCHITECTURE.md` that:
- Documents the 9 existing PHP files and how they connect
- Provides step-by-step implementation guides for building out empty directories
- Shows how to use the theme as a startup template
- Follows OOP standards with the `rt_` prefix

## Existing Code to Document

| File | Purpose |
|------|---------|
| `style.css` | WP theme header (React Template, v1.0.0, rt prefix) |
| `functions.php` | 3 lines: loads `core/bootstrap.php` |
| `header.php` | Standard WP head with `wp_head()`, `wp_body_open()` |
| `footer.php` | Footer using `rt_option()` for brand/contact, `wp_nav_menu()` |
| `index.php` | Main template — mounts `<div id="react-root">` |
| `page.php` | Page template — mounts `<div id="react-root" data-page="...">` |
| `single.php` | Single post — mounts `<div id="react-root" data-single="...">` |
| `search.php` | Search results — mounts `<div id="react-root" data-search="...">` |
| `404.php` | 404 page — mounts `<div id="react-root" data-404="true">` |

### Section 7: Recipes (How To)

#### Add a New Page
1. config/pages.php — add entry
2. pages/page-{slug}.php — create template
3. src/components/pages/Page{Slug}.js — create React component
4. Done

#### Add a React Component
1. Create in src/components/ (common/, layout/, or sections/)
2. Import in relevant page component
3. Style in src/styles/

#### Add an AJAX Call
1. config/ajax.php — register action
2. handlers/ajax/{name}.php — write callback
3. JS: RT.ajax('action', data).then(...)

#### Add a REST Route
1. config/rest.php — register route
2. handlers/rest/{name}.php — write callback
3. React: useApi() hook

#### Add an Admin Screen
1. config/admin.php — register menu/tab
2. admin/views/{view}.php — create view
3. RT.option('group', 'key') to read
