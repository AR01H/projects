## Part 2: Enhancement Plan

### Priority 1 — High Impact, No Backend Required

#### 1.1 Search Autocomplete / Instant Search
- **What**: Add a dropdown with product suggestions as user types in search bar
- **Files**: `Header.tsx`, new `SearchAutocomplete.tsx` component
- **Why**: Current search only works on submit — instant feedback improves discovery

#### 1.2 Product Comparison
- **What**: Allow users to select 2-4 products and compare specs side-by-side
- **Files**: New `CompareBar.tsx`, `ComparePage.tsx`, `useCompareStore.ts`
- **Why**: Key decision-making tool for handcrafted goods where specs matter

#### 1.3 Coupon / Promo Code Input
- **What**: Add coupon code input field in cart drawer and checkout
- **Files**: `CartDrawer.tsx`, `CheckoutPage.tsx`, new `useCouponStore.ts`
- **Why**: Every e-commerce site needs this; mock validation with known codes

#### 1.4 Product Variant Selection UI
- **What**: Wire up the existing `ProductVariant[]` data model to the Product Detail page
- **Files**: `ProductDetailPage.tsx`, new `VariantSelector.tsx`
- **Why**: Data model exists but no UI renders variant options (size/color/type)

#### 1.5 Sort on Mobile
- **What**: The mobile bottom sheet sort works but is missing sort on the main toolbar for tablet view
- **Files**: `ShopPage.tsx`
- **Why**: Consistent experience across breakpoints

#### 1.6 Infinite Scroll / Load More
- **What**: Replace full product list rendering with paginated load-more on ShopPage
- **Files**: `ShopPage.tsx`, `ProductGrid.tsx`
- **Why**: Performance — currently loads all products at once

### Priority 2 — Engagement & Trust

#### 2.1 Newsletter Form Functional Validation
- **What**: Add email validation, success/error states, and local "subscribed" flag
- **Files**: `Newsletter.tsx`
- **Why**: Currently just a visual component with no feedback

#### 2.2 Review Submission Form
- **What**: Allow users to submit a review (rating + text) on Product Detail page
- **Files**: `ProductDetailPage.tsx`, `reviews.ts` API
- **Why**: Reviews section says "be the first to review" but no form exists

#### 2.3 Social Proof Notification Popups
- **What**: Show small "X from Y just purchased" toasts periodically
- **Files**: New `SocialProofToast.tsx` component, added to `Layout.tsx`
- **Why**: Builds urgency and trust for new/limited products

#### 2.4 Back-in-Stock / Low-Stock Email Signup
- **What**: Add "Notify me when available" button for out-of-stock products
- **Files**: `ProductDetailPage.tsx`, new component
- **Why**: Captures demand and improves conversion

#### 2.5 Share Wishlist
- **What**: Generate a shareable link for a user's wishlist
- **Files**: `WishlistPage.tsx`, `useWishlistStore.ts`
- **Why**: Gifting use case — "here's what I want"

### Priority 3 — Polish & Production Readiness

#### 3.1 SEO Meta Tags (React Helmet)
- **What**: Add dynamic `<title>`, `<meta description>`, Open Graph tags per page
- **Files**: Install `react-helmet-async`, add to each page
- **Why**: Critical for organic traffic and social sharing

#### 3.2 Lazy Route Loading (Code Splitting)
- **What**: Use `React.lazy()` + `Suspense` for all page imports in App.tsx
- **Files**: `App.tsx`
- **Why**: Reduce initial bundle — 28 pages currently loaded eagerly

#### 3.3 Keyboard Navigation & Focus Management
- **What**: Tab through mega menu, close on Escape, focus trap in modals/drawers
- **Files**: `Header.tsx`, `MegaMenu.tsx`, `MobileNav.tsx`, `CartDrawer.tsx`
- **Why**: Accessibility compliance (WCAG 2.1 AA)

#### 3.4 Image Lazy Loading & WebP
- **What**: Add `loading="lazy"` to all below-fold images; add WebP/AVIF format hints
- **Files**: All image-rendering components
- **Why**: Performance — reduces bandwidth on initial load

#### 3.5 Toast Notification System
- **What**: Global toast context for "Added to cart", "Removed from wishlist", etc.
- **Files**: New `Toast.tsx` + `useToast.ts`, integrate into stores
- **Why**: Currently cart opens as feedback; toasts are more conventional

#### 3.6 404 Page Enhancement
- **What**: Add search bar, popular products, and navigation links to NotFoundPage
- **Files**: `NotFoundPage.tsx`
- **Why**: Keep users engaged when they hit a dead end

#### 3.7 Order Tracking Page
- **What**: Mock order tracking with status steps (Placed → Confirmed → Shipped → Delivered)
- **Files**: New `OrderTrackingPage.tsx`, new route
- **Why**: Post-purchase experience

### Priority 4 — Advanced Features

#### 4.1 User Authentication
- **What**: Login/Register pages, auth context, protected routes
- **Files**: New pages, `useAuthStore.ts`, Layout modifications
- **Why**: Prerequisite for order history, saved addresses, reviews

#### 4.2 User Profile & Order History
- **What**: Profile page with past orders, saved addresses, account settings
- **Files**: New `ProfilePage.tsx`, `OrderHistoryPage.tsx`
- **Why**: Retention and repeat purchase

#### 4.3 Real Backend Integration
- **What**: Replace mock API client with real HTTP calls to a CMS/backend
- **Files**: `client.ts`, all API modules, all store files
- **Why**: Production readiness — currently all data is static JSON

#### 4.4 Payment Gateway Integration
- **What**: Integrate Razorpay/Stripe for real payment processing
- **Files**: `CheckoutPage.tsx`, new payment API module
- **Why**: Currently checkout is a mock setTimeout

#### 4.5 Image CDN / Optimization Pipeline
- **What**: Serve images through Cloudinary/imgix with auto-format and resize
- **Files**: `getImageUrl.ts`, image components
- **Why**: Handcrafted product images need to be high quality but fast-loading
